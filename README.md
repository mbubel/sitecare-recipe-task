# SiteCare Recipe Task

This repo contains the completed technical task for SiteCare, based on the mockup provided. (https://stcrl.ink/36q)

## ✅ Functionality

- Displays the **publish date** and **last modified date** (only if different)
- Adds a **"Jump to Recipe"** button directly below the post title
- Matches layout, spacing, and styling from the mockup
- Title font: Roboto Slab  
- Meta and button font: Open Sans  
- All additions are scoped to single post views only  
- No core files or Event Calendar plugin were modified

---

## ▶️ Getting Started Locally

### 1. Clone the repo:

```bash
git clone https://github.com/mbubel/sitecare-recipe-task.git
cd sitecare-recipe-task
```

### 2. Start the container:

```bash
docker-compose up -d
```

### 3. Visit Local Host in your browser:

```bash
http://localhost:8000
```
